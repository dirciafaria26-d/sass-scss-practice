# SASS/SCSS Practice

## Objective
Convert traditional CSS into organized SCSS.

## What I learned
- Using variables to store reusable values
- Creating mixins for reusable styles
- Using nesting in SCSS
- Organizing code with partials
- Importing SCSS files using `main.scss`

## Folder Structure
- `abstracts/` — Variables and mixins
- `base/` — Global styles
- `layout/` — Container styles
- `components/` — Button and card styles
- `main.scss` — Imports all SCSS files
